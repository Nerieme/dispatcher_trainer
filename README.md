1. Вариант: диспетчер безопасности объекта.
   Цель: ускорить реакцию на угрозы, увеличить шанс предупредить ЧП.
   Краткое описание: пульт диспетчера позволяет отслеживать тревоги на объекте, устанавливать уровень угрозы, реагировать на угрозы и вести журнал.
   Диспетчер безопасности объекта контролирует работу датчиков и уровень задымления.
   Отслеживает работоспособность камеры наблюдения.

2. Фрагмент структуры проекта и список измененных файлов => Скриншот приложен.

3. std::string - используется везде, где необходимо текстовое представление данных в переменной.
   std::array - используется там, где не меняется количество объектов внутри массива.
   std::vector - используется для журналирования (log) и для хранения токенов полученной из консоли строки (после ее разбивки через splitCommand).
   обычные ссылки используются для передачи значений, которые возможно изменить, но при этом они будут занимать меньше памяти.
   const ссылки служат для передачи значений, которые защищены от записи (их нельзя менять), а также занимают меньше памяти.

4. << Доступные команды:\n
   << help                        - показать этот список
   << status                      - показать текущие параметры
   << set <parameter> <value>     - изменить значение параметра
   << event <severity> <source>   - добавить событие вручную
   << log                         - показать журнал событий
   << camera                      - показать статус камеры
   << visual                      - показать visual/AR-слои
   << exit                        - завершить работу
