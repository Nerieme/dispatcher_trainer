# dispatcher_trainer_lab2

## Инструкция сборки и запуска в Dev Container
cmake -S . -B build -DCMAKE_BUILD_TYPE=Debug
cmake --build build
./build/dispatcher_trainer

## Будущая визуализация клиента
Вариант: диспетчер энергосети.
Планируемые элементы визуального ряда:
1. Карта объекта разделенная на зоны с маркерами датчиков.
2. Цветовой статус зон под каждый датчик объекта: зелёный / жёлтый / красный.
3. Панель текущих параметров: уровень риска, связь, число тревог.
4. AR-метка критической зоны объекта над 3D-моделью.
5. AR-подсказка рекомендуемой команды диспетчера.
